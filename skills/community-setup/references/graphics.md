these sizes or larger. Source of truth: https://docs.tightknit.ai/branding#image-assets

## Nice to have

| Image | Where it appears | Size | Set with |
| --- | --- | --- | --- |
| Events, content library, and groups page banners | Top of those site pages | 2560 x 640 px (4:1) | `edit_site` |
| Feed banners | Top of each feed | 2560 x 640 px (4:1) | `update_feed` |
| Event cover images | Each event | 1080 x 1080 px (square, default) or 1280 x 720 px (wide) | `create_event` |
| Profile frame | Overlay on a member's photo when they earn an award | 512 x 512 px PNG with transparency | `create_award` |
| Login page image | Beside the login form | 1280 x 720 px | `manage_login_marketing_panel` |

Max file sizes are 2 to 4 MB depending on the image; the docs page lists each.
